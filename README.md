# FIRE Icons

100 open source icons for financial-independence and evidence-first personal
finance: the 4% rule and safe-withdrawal math, sequence-of-returns risk,
savings-rate and contribution caps, index funds and portfolio allocation,
spending trackers, FIRE milestones (coast, barista, lean), the study-design
vocabulary (backtests, Monte Carlo paths, survivor bias, calibration) that
separates a plan from a hunch. One outline style drawn on a 24px grid with a
2px stroke. Every icon is hand-authored for this set - nothing imported,
traced, or converted.

- 100 icons across 7 categories: Retirement Math, Market Risk, Savings & Income, Spending, Portfolio, Accounting, Evidence
- Format: static SVGs (`icons/`, file name = icon name) plus the full set as
  IconifyJSON at `fire.json`
- License: MIT

## Use

Drop the SVGs straight into a dashboard, doc, or deck, or consume the set
through Iconify tooling via `fire.json`. Icons are monotone and inherit
`currentColor`, so they style with plain CSS.
